# 设计标签与旧产品补标

## 一级分类与初始词汇

固定以下七个一级分类。每个小标签定义只能有一个 category_id 和一个归类条目，产品可以挂多个标签。表中分组是组织和查找标签的第二级，可扩展。图《风格拆解》中的小标签可录入字典，图中样例是展示方式。以下词汇用于启动打标，识别到可复用的新特征时可提议新增。

| 一级分类 ID | 展示名称 | 二级分组与示例 |
|---|---|---|
| form | 造型 | 整体形态（几何形态、有机形态、仿生形态）；基础形状（方体、柱体、楔体、多体块组合）；体块关系（一体化、分体式、嵌套式、叠加式）；整体比例（横向延展、纵向延展、扁平化、高重心）；轮廓特征（直线轮廓、流线轮廓、硬朗轮廓）；面与边界（平面、曲面、圆角、倒角、切面过渡）；分割关系（水平分割、垂直分割、功能分区分割）；对称与秩序（轴对称、非对称、重复排列）；模块关系（模块化、可扩展式、嵌入式模块） |
| color | 色彩 | 基调（冷色调、暖色调、中性色调）；色相（黑、白、灰、橙等）；明度（高、中、低）；饱和度（高、中、低、无彩色）；组合（单色、邻近色、互补色、对比色、渐变）；占比（主色、辅助色、点缀色）；对比（明暗、冷暖、饱和度、面积）；功能表达（功能分区色、状态提示色、安全警示色、操作引导色）；整体视觉感受转入视觉感知 |
| material | 材料 | 金属（铝合金、不锈钢、镀锌钢等）；塑料（ABS、PC、PP、PA、工程塑料等）；玻璃（普通玻璃、钢化玻璃、磨砂玻璃等）；复合材料（玻纤、碳纤等）；其他（橡胶、硅胶、木材、织物等）；材料组合（金属与塑料、玻璃与金属等）。表面质感、光泽程度按下方归类规则处理 |
| surface_manufacturing | 表面处理与制造表达 | 表面光泽（高光、半光、哑光）；纹理（磨砂、拉丝、喷砂、颗粒纹、条纹）；涂层（喷漆、粉末喷涂、电镀、阳极氧化）；金属表面处理（拉丝金属、抛光金属）；表面色彩工艺（本色、双色处理）；成型（一体成型、分体成型、注塑、压铸、钣金）；加工（CNC、激光切割、冲压）；连接（螺丝固定、卡扣连接、焊接、胶接）；接缝（隐藏接缝、规整接缝）；装配（一体化、模块化、外露紧固件）；连续性（连续表面、分段表面、拼接表面、局部蚀刻处理） |
| details | 细节 | 散热（散热孔、格栅、风道开口）；开孔（圆孔、长条孔、阵列孔）；接口（电源、通信、外露、隐藏接口）；内部布线（线束走向、线缆固定、走线分区）；控制（按钮、旋钮、拨杆、触控屏、键盘）；状态反馈（指示灯、显示屏、灯带）；紧固结构（螺丝、卡扣、铰链、固定支架）；连接部件（连接端子、连接器、线缆接口）；局部装饰（装饰条、装饰面板）；标识（品牌 Logo、产品型号标记、文字标识、警示图标）；细节组织（集中、分散、隐蔽式布局） |
| overall_style | 整体风格类型 | 极简主义、功能主义、现代科技风。根据案例开放补充，可同时存在多个有独立依据的风格 |
| visual_perception | 视觉感知 | 力量与体量（力量感、厚重感、稳固感）；轻盈与灵动（轻盈感、灵动感）；科技与未来（科技感、未来感、数字感）；精密与秩序（精密感、秩序感）；机械与结构（机械感、结构感、工业感）；亲和与温度（亲和感、温润感、柔和感）；高端与品质（高级感、品质感、精致感）；动态与活力（运动感、活力感、速度感）；稳重与可靠（稳重感、可靠感、安全感）；简洁与克制（简洁感、纯粹感、克制感、干净感） |

遇到图中的重叠项，按标签所断言的内容归类。同一个术语只有在含义不同且名称明确区分时可拆成两个标签。材料组成归材料，实际表面光泽或纹理归表面处理与制造表达，视觉上的冷暖、厚重或品质等印象归视觉感知。外壳「一体化体块」归造型，「一体成型」归表面处理与制造表达，后者要求工艺资料。「螺丝固定」表达连接工艺，「可见螺丝」表达可见细节。连续表面和具体功能件可以同时出现在同一产品的标签里。

## 单品打标

1. 审核①通过后，核对每张证据图的型号、变体、角度与可见部位。覆盖七类进行开放观察，尽量记下可复用或有辨识度的细节。允许某一类没有标签。图片中的背景、屏幕壁纸、配件及其它型号分别识别。
2. 把复合描述拆成可复用的小标签，保留完整原始观察、部位与证据定位。例如「通风孔为阵列长条孔」可以记录「散热孔」「长条孔」「阵列孔」，三者均归细节。相同标签用于多个部位时保留各部位证据。
3. 直接可见特征使用 OBSERVED，材料成分、加工方式及内部结构以适用型号的技术文字或可靠实物资料为依据。图片只能支持颜色或表面外观时，改记能够核验的观察。整体风格与视觉感知使用 INFERRED，链接具体可见细节并写明形成判断的理由。「可靠感」作为观感保存。
4. 在所属分类内比对字典定义、别名和边界。含义相同复用 ID，相关特征通过二级分组组织，单一新案例也可提交候选。为候选提供名称、唯一一级分类、二级分组、定义、例证和相近标签的区别。审核②可确认新增或调整映射。合并时保存旧 ID 到有效 ID 的映射和字典版本。
5. 审核②核对归类、证据和待确认项。网页按已审批标签 ID 检索，并可按一级分类展示；原始观察与待确认标签随待审数据保存。图片足以支撑的细标签可以沿共享设计特征跨行业浏览。

## 按需补标

新增可复用标签、重定标签定义、获得新证据，或用户指定补标范围时，读取已有库并生成候选清单。用别名、历史原始观察、部件和图片元数据召回跨品类候选；相似度仅用于排序。逐款核对原图或原文及型号变体。证据充分则提出追加，资料不足则登记待核验。默认按关联候选定向执行，全库扫描由明确的批量任务触发。

补标按产品 ID 输出变更建议，列出原标签、建议新增或调整项、部位、证据及触发原因。对已审核旧产品执行受影响设计标签的审核②，范围扩大到身份或系列时才重启对应审核。写入时按产品、标签、部位去重并合并证据，遇到已被修改的同一记录时重新读取并合并差异；删除、合并和冲突显式记录。正式写入沿用原授权流程。

用户以后可另配结构化产品字段，例如首发年份或设备生产年份，指定适用对象、值类型和来源后定向回查。需修改设计分类时，显式修订分类配置并记录版本。


## 联网检索与证据判定

每次新产品打标及旧产品补标都先执行网页检索与核验。以品牌、完整型号和目标特征检索，先打开官网产品页、型号对应的参数表、手册、官方图库或发布资料，再按需要查阅具备原始图文和明确型号的可靠第三方评测或实拍资料。记录实际查阅的页面 URL、资料版本和日期、适用型号或变体、图片区域或文本位置。搜索摘要只用于找来源。核对同型号、颜色版本及地区版本，遇到冲突时分别记录来源并提交审核。优先复用本次已经打开核验的原始网页。检索不到、页面无法访问或关键细节不可见时，记录限制并跳过依赖该证据的标签。

| 判定 | 写入规则 | 示例 |
|---|---|---|
| OBSERVED 有直接证据 | 引用适用型号的明确文字或实际查阅的清晰图片，说明哪段文字或哪个区域直接支撑小标签 | 官方规格明确外壳为铝合金；经型号核验的侧视图清楚显示阵列长条孔 |
| INFERRED 有依据的推断 | 引用具体图文及对应观察，写明从现象到标签的推断理由、适用范围和关键不确定项 | 从统一间距、规整接缝推断「秩序感」；从连续外壳与弱化的控制区推断「极简主义」 |
| 证据不足 | 跳过该标签，必要时只登记资料缺口。禁止写入标签分配和筛选索引 | 单凭金属光泽无法判断是铝合金，也无法确定采用阳极氧化 |

Markdown 审核报告分别列出有直接证据的标签和有依据的推断，并给出来源及判定理由。旧产品采用同一规则，相似案例只用于找到待复核对象。
## 从产品图判断色彩

已核实型号与版本、图像清楚时，直接记录肉眼可辨的可见颜色、所在部位和角色，例如「白色」对应柜门主体、「黑色」对应底座。标记 OBSERVED，注明图片 ID 和区域。产品图背景、阴影、反光与屏幕内容不纳入柜体配色。可清晰区分的色调或整体配色也可记录，同时注明观察范围。只有正视图时可记录「正面以白色为主」，全机是否单色需有覆盖依据。受偏色、滤镜或光照影响时，使用能确认的较粗色名或登记不确定项。精确色号、材质和涂层需要另有证据。

### 四类视觉标签
造型、色彩、整体风格类型、视觉感知先搜图。按完整型号、系列、规格及地区版本查官网图集、手册、发布会和可靠实拍，尽量覆盖正侧背、顶部、三分之四视角及细节。重复转载或裁切不增加独立视角。登记角度、来源、版本、可见范围及下载状态，核验后保存原图。
造型与色彩可用清晰图片直接观察，记录部位和图像 ID。仅取得可信配图说明或版本匹配线索时，标签为暂定推断。整体风格与视觉感知由多项可见特征综合推断。另检索官方宣传稿和产品文案，辅助解释设计意图和定位；宣传词与技术参数不能单独证明外观。对缺失角度和不明确版本明确记录范围，不能从正面推及整机。无需寻找与字典标签逐字对应的官方原句。
