## 产品设计 Skills

| Skill | 负责的阶段 |
| --- | --- |
| [Product Research](skills/product-research/SKILL.md) | 解析产品 URL，整理基础信息、图片、七类设计标签和证据 |
| [跨行业设计案例检索](skills/cross-industry-product-discovery/SKILL.md) | 根据所选标签外部检索，提交候选名称、行业、业界评价和网页链接供人工初筛 |

Product Research 先解析原产品并生成标签。用户选标签后启动跨行业检索。用户勾选的候选再交回 Product Research，完成详细解析、打标与审核。
